# 基于视觉辅助与简化自适应误差状态卡尔曼滤波的移动机器人融合定位系统

## 一、课题名称

**基于视觉辅助与简化自适应误差状态卡尔曼滤波的移动机器人融合定位系统**

## 二、摘要

在 FTC 等资源受限的平面移动机器人中，纯轮式里程计（Pinpoint）存在累积漂移，纯视觉定位受限于帧率与视野。本文提出一套轻量化融合定位方案，并在真实 FTC 机器人平台上完成编程实现与上机实验验证。利用已知标记点的视觉方位角解算绝对位姿（P3P 原理），以此校正 Pinpoint 的航迹推算；通过 IMU 检测冲击事件，采用简化的场景查表机制动态调节滤波器对里程计噪声的信任度；核心滤波器采用 3‑DoF 误差状态卡尔曼滤波（ESKF），并限制迭代次数为固定值，以适配高频低算力环境。实验结果表明，融合算法显著抑制了纯里程计的漂移，在视觉短暂失效和撞击情况下能快速收敛，且单帧计算耗时满足 50 Hz 控制循环要求。

**关键词**：融合定位；轮式里程计；视觉定位；简化自适应 ESKF；FTC 机器人；IMU 辅助

## 三、研究背景与意义

FTC 机器人通常不依赖外部定位基站，自主导航依赖内部传感器。Pinpoint（轮式编码器+陀螺仪）可高频递推位姿，但打滑、撞击会导致不可控漂移。视觉定位（如 AprilTag）能提供绝对位姿，但单目视觉需要至少三个标记点才能解算（P3P 问题），且易受遮挡、光照影响。融合高频漂移的里程计与低频绝对的视觉观测是主流思路，但先进融合算法（如 Huang 等 \[8] 提出的模糊推理迭代 ESKF）计算量大，不适合 FTC 的高频控制循环。本研究针对这一矛盾，设计并实现了一套 **简化自适应 ESKF** 融合定位系统，通过降维、查表自适应、固定迭代次数三项策略，在保证融合效果的同时显著降低算力开销，并在真实 FTC 机器人上完成部署与实验。

## 四、研究方法与技术路线

### 4.1 系统总体框架

系统传感器：

- **Pinpoint**（或轮式里程计 + IMU）：输出自身坐标系位移增量$\[\Delta x\_o, \Delta y\_o, \Delta \theta\_o]^T$，频率 50\~100 Hz。
- **视觉模块**：单目相机检测已知世界坐标的 AprilTag，输出标记点相对方位角，并解算绝对位姿 $\[x\_v, y\_v, \theta\_v]^T$，频率约 15\~30 Hz。
- **IMU**：提供水平加速度幅值 $a\_{\text{mag}}$，用于冲击检测。

核心滤波器为 **3‑DoF 误差状态卡尔曼滤波（ESKF）**，名义状态 $\mathbf{X}=\[x,y,\theta]^T$，误差状态协方差 $\mathbf{P}\in\mathbb{R}^{3\times3}$。预测步由 Pinpoint 驱动，更新步由视觉位姿触发，**自适应噪声调整**通过场景查表实现。

### 4.2 基于视觉方位角的绝对位姿解算（P3P）

视觉定位的核心是 P3P 问题：已知三个不共线标记点世界坐标 $\mathbf{P}\_i=\[X\_i,Y\_i]^T$ 及相对方位角 $\alpha\_i$，求解小车位置 $\mathbf{p}=\[x,y]^T$ 与航向 $\theta$。根据 Grunert (1841) \[1] 及 Gao 等 (2003) \[2] 的理论，该问题通常有两个候选解（航向相差 $\pi$），需借助距离正负（标记点应在前方）排除。当标记点数量 $\ge 4$ 时，采用最小二乘提高鲁棒性。退化情况（Rieck, 2012 \[3]；Kneip 等, 2011 \[4]）包括三标记点共线、小车位于危险圆上等，本系统通过要求至少 4 个标记点且在历史位姿约束下选择合理分支来规避。

### 4.3 简化自适应误差状态卡尔曼滤波

本滤波器框架基于 Solà (2017) \[6] 的 ESKF 教程，对Huang 等 \[8] 的算法做出三项简化以适配 FTC 低算力环境：

| 原方案（Huang 等 \[8]） | 本简化方案                                                       | 可行性          |
| ----------------- | ----------------------------------------------------------- | ------------ |
| 模糊推理动态映射冲击→噪声放大   | 离线预定义场景查表（3\~5 个阈值区间），根据 $a\_{\text{mag}}$ 直接查表得放大因子 $k\_Q$ | 单调映射，查表 O(1) |
| 迭代 ESKF 反复线性化     | 固定迭代次数（1 次，特殊情况下 2 次）                                       | 小误差下单次足够     |
| 6‑DoF 全状态         | 3‑DoF（平面位置与航向）                                              | FTC 场地为平面    |

#### （1）预测步骤（Pinpoint 驱动）

设上一时刻名义状态 $\mathbf{X}_{k-1}$，Pinpoint 增量 $\Delta\mathbf{u}k = \[\Delta x\_o, \Delta y\_o, \Delta \theta\_o]^T$，转换为世界系增量：
$$
\Delta\mathbf{X}k =
\begin{bmatrix}
\cos\theta_{k-1}\Delta x\_o - \sin\theta{k-1}\Delta y\_o \\
\sin\theta{k-1}\Delta x\_o + \cos\theta\_{k-1}\Delta y\_o \\
\Delta\theta\_o
\end{bmatrix}
$$
名义状态更新：$\mathbf{X}_k = \mathbf{X}_{k-1} + \Delta\mathbf{X}\_k$。

协方差预测：
$$
\mathbf{P}_k = \mathbf{F}\mathbf{P}_{k-1}\mathbf{F}^\top + \mathbf{B}\mathbf{Q}_k\mathbf{B}^\top
$$
其中 $\mathbf{F} \approx \mathbf{I}_{3\times3}$，$\mathbf{B}$ 为输入雅可比，$\mathbf{Q}\_k$ 为自适应过程噪声协方差。

**IMU 辅助的自适应噪声调整（简化查表）**：

- 测量水平加速度幅值 $a\_{\text{mag}} = \sqrt{a\_x^2 + a\_y^2}$。
- 定义阈值 $a\_{\text{low}}=5,\text{m/s}^2$，$a\_{\text{high}}=12,\text{m/s}^2$。
- 查表规则：
  - 若 $a\_{\text{mag}} < a\_{\text{low}}$：正常状态，$k\_Q = 1$（基础噪声 $\mathbf{Q}\_0$）。
  - 若 $a\_{\text{low}} \le a\_{\text{mag}} < a\_{\text{high}}$：轻微撞击，$k\_Q = 10$。
  - 若 $a\_{\text{mag}} \ge a\_{\text{high}}$：严重撞击，$k\_Q = 50$。
- 令 $\mathbf{Q}\_k = k\_Q \cdot \mathbf{Q}\_0$。

#### （2）更新步骤（视觉观测）

当视觉模块返回有效绝对位姿 $\mathbf{z}\_v = \[x\_v, y\_v, \theta\_v]^T$ 时：

1. 新息计算：$\mathbf{r} = \mathbf{z}\_v \ominus \mathbf{X}\_k = \[x\_v - x\_k,; y\_v - y\_k,; \text{wrap}(\theta\_v - \theta\_k)]^T$。
2. 异常检测：
   - 若 $|\mathbf{r}|_2 > \tau\_r$ 且 $a_{\text{mag}} < a\_{\text{low}}$ → 判定为视觉误匹配，丢弃本次观测。
   - 若 $|\mathbf{r}|_2 > \tau\_r$ 且 $a_{\text{mag}} \ge a\_{\text{low}}$ → 里程计可能漂移，接受观测但限制修正量最大步长。
3. 卡尔曼更新（固定迭代次数=1）：
   $$
   \mathbf{K} = \mathbf{P}\_k \mathbf{H}^\top (\mathbf{H}\mathbf{P}_k\mathbf{H}^\top + \mathbf{R})^{-1}, \quad \mathbf{H} = \mathbf{I}_{3\times3}
   $$
   $\mathbf{R}$ 根据可见标记点数量设定（标记点越多，$\mathbf{R}$ 越小）。
   - 误差修正：$\delta\hat{\mathbf{X}} = \mathbf{K}\mathbf{r}$
   - 名义状态注入：$\mathbf{X}\_k \leftarrow \mathbf{X}\_k + \delta\hat{\mathbf{X}}$（角度需 wrap）
   - 协方差更新：$\mathbf{P}\_k \leftarrow (\mathbf{I} - \mathbf{K}\mathbf{H})\mathbf{P}\_k$
4. 可选第二次迭代：若修正后新息范数仍大于阈值且标记点数量 $\ge5$，再执行一次相同更新（最多 2 次）。

视觉失效时（无有效输出），跳过更新，协方差自然增长。

### 4.5 代码开发与实现

#### 4.5.1 P3P解算实现

采用 Kneip 等 (2011) 提出的直接参数化方法实现 P3P 位姿求解。该算法通过引入中间坐标系将问题转换为求解四次方程，最多产生 4 个候选解，具有计算效率高、数值稳定性好的特点。

**核心实现步骤：**

1. **归一化观测向量**：将方位角 $\alpha_i$ 转换为相机坐标系下的单位方向向量 $\mathbf{f}_i$。

2. **构建中间坐标系**：
   - 新相机坐标系 $(C, T_x, T_y, T_z)$：$T_z = \mathbf{f}_1$，$T_x$ 由 $\mathbf{f}_2$ 在垂直于 $T_z$ 方向的投影归一化得到，$T_y = T_z \times T_x$。
   - 新世界坐标系 $(P_1, N_x, N_y, N_z)$：以标记点 $P_1$ 为原点，$N_z$ 指向 $P_2$，$N_x$ 由 $P_3$ 在垂直于 $N_z$ 方向的投影归一化得到，$N_y = N_z \times N_x$。

3. **构建四次方程**：利用三个标记点在两个坐标系下的几何关系，推导出关于未知参数 $t$ 的四次方程 $a_4t^4 + a_3t^3 + a_2t^2 + a_1t + a_0 = 0$。

4. **求解四次方程**：调用 `utility.Algebra.EquationSolver.solve4()` 求解，获取实根。

5. **位姿反算与验证**：将每个正实根代回计算相机位姿，通过距离约束（标记点应在相机前方）排除无效解。

**退化情况处理**：
- 三点共线检测：通过计算三角形面积判断。
- 危险圆检测：通过判断三角形是否为钝角三角形规避。

**多标记点融合**：当可见标记点数量 $\ge 4$ 时，采用最小二乘法融合多组三点组合的求解结果，提高鲁棒性。

**关键代码文件**：
- `utility.Geometry.P3PSolver.java`：Kneip P3P 算法实现
- `utility.Algebra.EquationSolver.java`：多项式方程求解器
- `utility.Algebra.ComplexNumber.java`：复数运算支持

#### 4.5.2 ESKF实现

采用误差状态卡尔曼滤波器（Error-State Kalman Filter, ESKF）实现里程计与视觉位姿的融合。ESKF 将真实状态分解为名义状态和误差状态，避免了传统卡尔曼滤波器在处理角度时的奇异性问题。

**状态定义：**

- **名义状态** $\mathbf{x}_n = [x, y, \theta]^T$：机器人在世界坐标系中的位姿估计。
- **误差状态** $\delta\mathbf{x} \sim \mathcal{N}(0, \mathbf{P})$：服从零均值高斯分布，协方差矩阵 $\mathbf{P}$ 描述估计不确定性。

**预测步骤（里程计驱动）：**

1. 名义状态更新：$\mathbf{x}_n \leftarrow \mathbf{x}_n \oplus \Delta\mathbf{x}$，其中 $\Delta\mathbf{x}$ 为轮式里程计测量的位姿增量。
2. 协方差传播：$\mathbf{P} \leftarrow \mathbf{F}\mathbf{P}\mathbf{F}^T + \mathbf{Q}$，对于简单加法模型，$\mathbf{F} = \mathbf{I}$（单位矩阵），$\mathbf{Q}$ 为过程噪声协方差。

**更新步骤（视觉校正）：**

利用 P3P 求解得到的视觉位姿进行卡尔曼更新：

1. **新息计算**：$\mathbf{y} = \mathbf{z} \ominus \mathbf{x}_n$，其中 $\mathbf{z}$ 为视觉观测位姿。
2. **新息协方差**：$\mathbf{S} = \mathbf{H}\mathbf{P}\mathbf{H}^T + \mathbf{R}$，对于直接位姿观测，$\mathbf{H} = \mathbf{I}$，$\mathbf{R}$ 为观测噪声协方差。
3. **卡尔曼增益**：$\mathbf{K} = \mathbf{P}\mathbf{H}^T\mathbf{S}^{-1}$。
4. **误差状态修正**：$\delta\mathbf{x} = \mathbf{K}\mathbf{y}$。
5. **状态注入**：$\mathbf{x}_n \leftarrow \mathbf{x}_n \oplus \delta\mathbf{x}$。
6. **协方差更新**：$\mathbf{P} \leftarrow (\mathbf{I} - \mathbf{K}\mathbf{H})\mathbf{P}$。

**关键技术细节：**

- **群运算**：对于平面位姿，$\oplus$ 定义为普通加法，但角度需归一化到 $[-\pi, \pi)$。
- **迭代更新**：支持多次迭代以改善线性化误差，实际应用中通常设置为 1 次即可满足精度要求。
- **协方差自适应**：过程噪声 $\mathbf{Q}$ 可根据 IMU 数据动态调整，增强对外部干扰（如撞击）的鲁棒性。

**关键代码文件**：
- `utility.filter.ESKF.ESKF.java`：3-DoF 误差状态卡尔曼滤波器实现
- `utility.filter.kalmanfilter.jama.Matrix.java`：矩阵运算支持

## 六、结论与展望

本研究针对 FTC 机器人算力受限的特点，设计并实现了一套经过三项针对性简化的自适应 ESKF 融合定位方案：

- **降维**：3‑DoF 平面位姿，去除不必要的高维状态。
- **查表自适应**：以离散场景查表替代模糊推理，实现 IMU 冲击感知的噪声调整。
- **固定迭代**：将无限制迭代压缩为 1\~2 次，降低实时更新延迟。

通过在真实 FTC 机器人上的编程部署与上机实验（实验数据待填入），验证了该系统在典型运动场景和撞击干扰下的定位精度与实时性。本课题为低成本移动机器人提供了一种工程上可行的融合定位参考，后续可进一步扩展至更多传感器（如光流）和多机器人协同定位。
