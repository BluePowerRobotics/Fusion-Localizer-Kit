# 融合定位系统升级说明：IMU 辅助预测 + 自适应观测噪声

## 1. 背景与动机

原版 `FusionLocalizer`（EKF/UKF + Pinpoint + Limelight）存在以下不足：

- **爬坡定位误差**：Pinpoint 里程计在斜坡上测量的是斜距，虽有 `PinpointD3Localizer` 的几何投影补偿，但坡度变化时 Pinpoint 可能短暂腾空，导致速度观测不可靠。
- **飞坡期间协方差爆炸**：碰撞/腾空时，原自适应逻辑（提升过程噪声 Q）使滤波器放弃预测，完全依赖低频视觉修正，位姿估计抖动甚至发散。
- **加速度信息未被利用**：外接加速度计（如 BNO055）可提供高频动力学信息，但原系统仅用 IMU 角速度做 Q 自适应，未接入加速度。

本升级通过引入 **外接加速度计作为控制输入**，结合 **Hub IMU 完整姿态** 进行三维旋转，将加速度投影到世界坐标系后驱动 5 维状态 EKF/UKF 预测。同时，**将自适应对象由 Q 转移至 Pinpoint 速度观测噪声 R**，并在判定信号中引入 **竖直加速度** 与 **角速度** 的组合，实现更鲁棒的异常检测。

***

## 2. 新方案概述

### 2.1 状态空间扩展（5 维）

```
X = [x, y, θ, Vx, Vy]ᵀ
```

- `x, y`：场地水平位置（英寸）
- `θ`：航向（弧度）
- `Vx, Vy`：世界坐标系下的线速度（英寸/秒）

### 2.2 数据角色重构

| 传感器           | 原角色              | 新角色                |
| ------------- | ---------------- | ------------------ |
| Pinpoint 里程计  | 控制输入（速度）         | **高频观测**（速度 + 角速度） |
| 外接加速度计（x前 y左） | 未使用              | **控制输入**（体加速度）     |
| Hub IMU（姿态）   | 仅用于 Q 自适应和 D3 补偿 | **姿态旋转基准**（完整三维旋转） |
| Limelight     | 低频绝对观测           | 低频绝对观测（不变）         |

### 2.3 核心思想

1. **加速度驱动预测**：外接加速度计测得的体加速度经完整姿态旋转得到世界加速度，二次积分得到位置增量，一次积分得到速度增量。
2. **Pinpoint 作为速度观测**：用于修正加速度积分产生的速度漂移。
3. **自适应 R\_pinpoint**：根据竖直加速度和角速度动态调节对 Pinpoint 速度的信任度（而非调节 Q）。
4. **Limelight 作为位置观测**：提供长期绝对约束。

## 3. 坐标系定义与姿态映射

### 3.1 三套坐标系

| 坐标系                | X 轴 | Y 轴 | Z 轴 | 用途                             |
| ------------------ | --- | --- | --- | ------------------------------ |
| 外接加速度计             | 前   | 左   | 上   | 提供体加速度 `a_body = [ax, ay, az]` |
| RR 体坐标系            | 前   | 左   | 上   | 运动模型所在坐标系                      |
| Hub IMU (Robot CS) | 右   | 前   | 上   | `YawPitchRollAngles` 输出        |

**关键结论**：外接加速度计与 RR 体坐标系方向一致，**无需轴交换**。

### 3.2 Hub IMU 姿态角度 → RR 体坐标系的映射

| 角度          | Hub IMU 输出   | 旋转轴 (Robot CS) | 对应 RR 体轴  | 物理含义       |
| ----------- | ------------ | -------------- | --------- | ---------- |
| Yaw (`ψ`)   | `getYaw()`   | Z（上）           | Z（上）      | 航向         |
| Pitch (`θ`) | `getPitch()` | **X（右）**       | **-Y（右）** | 前后倾斜（抬头为正） |
| Roll (`φ`)  | `getRoll()`  | **Y（前）**       | **X（前）**  | 左右倾斜（左侧抬起为正） |

**代码中直接使用**：

```java
YawPitchRollAngles angles = hubImu.getRobotYawPitchRollAngles();
double yaw = angles.getYaw(AngleUnit.RADIANS);
double pitch = angles.getPitch(AngleUnit.RADIANS);
double roll = angles.getRoll(AngleUnit.RADIANS);
```

## 4. 体加速度 → 世界加速度的完整旋转

### 4.1 旋转矩阵（Z-Y-X 内旋）

从 RR 体坐标系到世界水平坐标系的旋转矩阵为：

```
R = Rz(ψ) · Ry(-θ) · Rx(φ)
```

其中：

- `Rx(φ)`：绕 X(前) 轴旋转 Roll（左右倾斜）
- `Ry(-θ)`：绕 -Y(右) 轴旋转 Pitch（前后倾斜），等价于绕 +Y(左) 轴旋转 -θ
- `Rz(ψ)`：绕 Z 轴旋转 Yaw（航向）

> **符号约定说明**：这里 Pitch 采用 `Ry(-θ)`（θ 前仰为正），而非 `Ry(+θ)`。这一约定与实测一致（pitch 前仰为正、roll 左侧抬起为正），并决定了 §4.2 中交叉项 `-ay·sinθ·sinφ` 的负号。旧版 D3 推导曾误用 `Ry(+θ)`，导致交叉项符号相反，现已修正（见 `D3Localizer/Theory.md`）。

### 4.2 展开式（水平分量）

设体加速度 `a_body = [ax, ay, az]`（单位 in/s²），则世界加速度水平分量为：

```
A = ax·cosθ - ay·sinθ·sinφ - az·sinθ·cosφ
B = ay·cosφ - az·sinφ

ax_w = A·cosψ - B·sinψ
ay_w = A·sinψ + B·cosψ
```

> 注：`az` 为竖直方向加速度（外接加速度计 Z 轴，向上为正）。

### 4.3 物理意义

- 静态斜坡上，`ax≈ay≈az≈0`（线性加速度已剔除重力），旋转后 `ax_w≈ay_w≈0`，无漂移。
- 加速上坡时，`ax` 经 Pitch 投影为水平加速度，真实反映水平加速力。
- 飞坡时，`az` 接近 `-g`（自由落体），但结合零速检测可避免积分发散。

## 5. 自适应 R\_pinpoint 逻辑

原版使用 IMU 角速度/角加速度自适应 Q。新版本改为 **自适应 Pinpoint 速度观测噪声 R**。

> **两种实现变体**：本方案现有 D3（默认）与 D2（简化）两种 R_pin 判定方式，二者仅在「Pinpoint 速度观测不可靠」的判据上不同，加速度预测、Q 固定、视觉 R 逻辑完全相同：
>
> | 变体 | 实现类 (EKF / UKF) | 里程计 | R_pin 判据 |
> | --- | --- | --- | --- |
> | D3（默认） | `AdaptiveEKF5DLocalizer` / `AdaptiveUKF5DLocalizer` | `PinpointD3Localizer`（3D 斜坡补偿） | `\|az\|` + 角速度（§5.1–§5.3） |
> | D2（简化） | `AdaptiveEKF5DLocalizer_D2` / `AdaptiveUKF5DLocalizer_D2` | `PinpointLocalizer`（标准 2D） | pitch/roll 倾角（§5.4，yaw 例外仍用角加速度） |

### 5.1 判定信号设计

| 方向        | 传感器信号 | 物理含义     | 阈值       | <br />    | <br />           | <br />           | <br />                                   |
| --------- | ----- | -------- | -------- | :-------- | :--------------- | :--------------- | :--------------------------------------- |
| **X**（前后） | \`    | az       | `与`      | pitchRate | \` 组合            | 竖直加速度变化 + 前后倾斜速率 | `AZ_THRESHOLD` + `ANGULAR_VEL_THRESHOLD` |
| **Y**（左右） | \`    | az       | `与`      | rollRate  | \` 组合            | 竖直加速度变化 + 左右倾斜速率 | 同上                                       |
| **θ**（航向） | \`    | yawAccel | \`（角加速度） | 旋转冲击      | `JERK_THRESHOLD` | <br />           | <br />                                   |

**组合方式**：将 `az` 的绝对值与对应轴角速度的绝对值**加权求和**（或取最大值），作为有效幅值。当幅值超过阈值时，增大对应方向的 R\_pinpoint，表示 Pinpoint 速度观测不可信，滤波器更依赖加速度积分。

### 5.2 映射到 R\_pinpoint

每个方向的 boost 因子独立更新（与旧 Q 逻辑相同）：

```
if magnitude > threshold:
    R_boost = min(R_BOOST_MAX, R_boost × (1 + magnitude / threshold))
else:
    R_boost = max(1.0, R_boost × R_DECAY)

R_pinpoint[i] = R_base[i] × R_boost[i]
```

其中 `R_base` 为 Pinpoint 速度观测噪声基值（如 `0.1 in²/s²`）。

### 5.3 为何选择竖直加速度 + 角速度？

- **竖直加速度** **`az`** 反映机器人是否处于非支撑状态（飞坡、颠簸）或受到垂向冲击，这些时刻 Pinpoint 轮子可能打滑或离地，速度不可靠。
- **角速度** **`pitchRate/rollRate`** 反映坡度变化，与 `az` 结合可区分“斜坡行驶”（角速度大但 `az` 接近 0）和“飞坡”（角速度大且 `az` 偏离 0），避免在正常斜坡上错误放大 R。

***

### 5.4 D2 简化模式的判定（仅用角度）

D2 模式面向标准 2D 底盘与相对平坦的场地，用更简单的判据取代 D3 的「竖直加速度 + 角速度」组合：

| 方向 | 判定信号 | 阈值 | 物理含义 |
| --- | --- | --- | --- |
| X（前后速度） | `|pitch|` | `ANGLE_THRESHOLD` (≈0.15 rad ≈ 8.6°) | 机身前后倾角大 → 前后速度观测不可靠 |
| Y（左右速度） | `|roll|` | `ANGLE_THRESHOLD` | 机身左右倾角大 → 左右速度观测不可靠 |
| θ（航向） | yaw 角加速度 | `JERK_THRESHOLD` | 旋转冲击（与 D3 一致的例外项） |

即「仅用角度判定，yaw 除外仍用角加速度」。放大/衰减规则与 §5.2 的 `updateRBoost` 完全一致：

```
if |pitch| > ANGLE_THRESHOLD:  rBoostX 增大
if |roll|  > ANGLE_THRESHOLD:  rBoostY 增大
```

与 D3 相比，D2 不再使用 `AZ_THRESHOLD` / `ANGULAR_VEL_THRESHOLD`，也无需 `PinpointD3Localizer` 的斜坡补偿投影，适用场景更简单、调参更少。

## 6. 滤波器（EKF5D/UKF5D）修改要点

### 6.1 状态传播（预测）

对每个 sigma 点（UKF）或直接用均值（EKF）执行：

```
ax_w = A(ax, ay, az, θ, φ)·cosψ - B(ay, az, φ)·sinψ
ay_w = A·sinψ + B·cosψ

x'  = x + Vx·dt + 0.5·ax_w·dt²
y'  = y + Vy·dt + 0.5·ay_w·dt²
θ'  = θ + ω_pin·dt
Vx' = Vx + ax_w·dt
Vy' = Vy + ay_w·dt
```

其中 `ω_pin` 来自 Pinpoint 角速度观测（作为控制输入的一部分）。

### 6.2 观测更新

- **Pinpoint 速度观测（每帧）**：\
  观测向量 `z_pin = [vx_body, vy_body, ω_pin]`，由状态 `Vx, Vy, θ` 映射：
  ```
  vx_body_pred = Vx·cosθ + Vy·sinθ
  vy_body_pred = -Vx·sinθ + Vy·cosθ
  ```
  R 矩阵采用自适应值。
- **Limelight 位置观测（低频）**：\
  观测向量 `z_lim = [x, y, θ]`，R 矩阵仍由 MT1 stdDev 自适应。

### 6.3 零速检测（新增）

当同时满足：

- `|ax| < ZERO_VEL_ACCEL_THRESHOLD`（体加速度小）
- `|vx_pin| < ZERO_VEL_PINPOINT_THRESHOLD`（Pinpoint 速度接近零）

则强制将速度状态 `Vx, Vy` 重置为 0，防止静止时加速度积分漂移。

## 7. 可调参数列表

| 参数名                           | 含义                 | 建议初始值        | 适用    |
| ----------------------------- | ------------------ | ------------ | ----- |
| `Q_pos`                       | 位置过程噪声             | 0.01 in²/s   | 5 维状态 |
| `Q_theta`                     | 角度过程噪声             | 0.002 rad²/s | 5 维状态 |
| `Q_vel`                       | 速度过程噪声             | 0.5 in²/s³   | 5 维状态 |
| `R_pin_base`                  | Pinpoint 速度观测噪声基值  | 0.1 in²/s²   | 自适应 R |
| `R_lim_base`                  | Limelight 位置观测噪声基值 | 0.01 in²     | 不变    |
| `AZ_THRESHOLD`                | 竖直加速度触发阈值          | 2.0 in/s²    | 自适应 R |
| `ANGULAR_VEL_THRESHOLD`       | 角速度触发阈值            | 1.0 rad/s    | 自适应 R |
| `JERK_THRESHOLD`              | yaw 角加速度阈值         | 4.0 rad/s²   | 自适应 R |
| `R_BOOST_MAX`                 | 最大 R 放大倍数          | 20.0         | 自适应 R |
| `R_DECAY`                     | R boost 衰减系数       | 0.85         | 自适应 R |
| `ZERO_VEL_ACCEL_THRESHOLD`    | 零速检测加速度阈值          | 0.5 in/s²    | 零速检测  |
| `ZERO_VEL_PINPOINT_THRESHOLD` | 零速检测速度阈值           | 0.5 in/s     | 零速检测  |

> **D2/D3 专属参数补充**：
> - `AZ_THRESHOLD`、`ANGULAR_VEL_THRESHOLD` 仅 D3 使用；
> - `ANGLE_THRESHOLD`（默认 0.15 rad ≈ 8.6°）为 D2 专用，替代上述两阈值；
> - `JERK_THRESHOLD`、`R_PIN_BASE`、`R_PIN_THETA_BASE`、`R_BOOST_MAX`、`R_DECAY` 以及零速检测阈值为 D2/D3 共用。

## 8. 与旧算法对比（性能提升）

| 场景         | 旧算法 (3 维, Q 自适应)         | 新算法 (5 维, R\_pin 自适应)                                                 | 提升原因                |
| ---------- | ------------------------ | --------------------------------------------------------------------- | ------------------- |
| **正常行驶**   | 精度良好                     | 精度良好，响应略快                                                             | 加速度积分提供更平滑的速度过渡     |
| **爬坡（短坡）** | Q 增大，依赖视觉修正              | R\_pin 增大，依赖加速度预测，视觉仍然可用                                              | 完整姿态旋转消除重力残差，漂移小    |
| **爬坡（长坡）** | Q 持续增大 → 预测权重低，视觉帧率受限时滞后 | R\_pin 由 `az` 和角速度判定，正常斜坡 `az` 小 → R 不增大，Pinpoint 仍有效修正               | 区分“坡度变化”和“飞坡”，避免误判  |
| **飞坡/腾空**  | Q 爆炸，协方差发散，视觉恢复后剧烈跳变     | R\_pin 因 `az` 偏离而增大，但 Q 固定，预测（匀速运动）精确，协方差稳定                           | 加速度积分在飞坡时产生零漂移，弹道完美 |
| **碰撞急停**   | Q 增大，随后衰减                | R\_pin 因 `az` 和角速度增大而增大，但 Pinpoint 速度观测被削弱，滤波器依赖加速度积分（急停时加速度反向），响应更自然 | 加速度直接反映受力变化         |

## 9. 与 `PinpointD3Localizer` 的协同

- `PinpointD3Localizer` 负责将 Pinpoint 测得的**斜距速度**投影为**水平速度**，其旋转矩阵与我们使用的姿态映射**完全一致**。
- 新滤波器中，Pinpoint 速度观测（体坐标系）是从状态中推算的，与 D3 的补偿输出（水平体速度）可互相校验。
- 两者共享同一套 Hub IMU 姿态数据，保证了坐标系一致性。

***

## 10. 注意事项与验证要点

1. **外接加速度计必须已剔除重力**（如 BNO055 的 `getAcceleration()`，融合模式下为线性加速度）。
2. **单位转换**：加速度若为 m/s²，须 ×39.3701 转 in/s²。
3. **零速检测**阈值需根据实际噪声调整，建议在静止状态下观测加速度波动来设定。
4. **UKF 的 sigma 点传播**：需逐点旋转加速度（因每个 sigma 点航向不同），EKF 则可使用均值航向。
5. **验证测试**：
   - 静态斜坡：位置漂移 < 0.5 in / 5s。
   - 飞坡测试：位置估计应平滑，落点误差 < 3 in。
   - 长坡道：Pinpoint 修正应始终有效，视觉修正仅做微调。

***

## 11. 总结

本升级通过引入 **外接加速度计 + 完整姿态旋转 + 自适应 R\_pinpoint**，将定位系统从“被动测量”提升为“主动预测”，在保留原有视觉/里程计优势的同时，显著增强了爬坡和飞坡场景下的鲁棒性与精度。修改范围可控（仅需替换滤波器类、增加加速度读取和旋转逻辑），并保留了与 RoadRunner 的完全兼容性。
